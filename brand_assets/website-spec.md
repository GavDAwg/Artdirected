# ART.DIRECTED
Website Specification
Production Build (Claude Code)

---

# Overview

Build a minimal portfolio website for a creative studio called **ART.DIRECTED.**

The studio presents a new production model for creating campaign imagery using a hybrid of human art direction and AI execution.

The website should feel like:

- a photography portfolio
- a campaign archive
- a creative studio website

It should **not resemble** a tech startup or AI product site.

The homepage is a **single scrolling page**.

Campaigns open as **dedicated project pages**.

Imagery should always be the dominant element.

---

# Design Principles

Visual tone should feel:

- calm
- editorial
- minimal
- image-led

Avoid:

- cards
- drop shadows
- heavy UI
- complex animations
- SaaS-style layouts

Use:

- large typography
- generous whitespace
- subtle motion
- full-width imagery

# Approach

Section heading

Approach

Copy

Every project begins with a conversation.

We interpret the brief, develop visual directions, and present campaign mock-ups before production begins.

Once a direction is approved, final imagery is produced digitally using the client’s product photography as the foundation.
